# Data access and redistribution

MIMIC-IV and the eICU Collaborative Research Database are available through
PhysioNet to qualified users who complete the required credentialing and agree
to the applicable data-use agreements.

This repository does not redistribute:
- source database tables;
- patient-level cohort files;
- sequential-trial panels;
- patient/stay identifiers;
- patient-level weights;
- intermediate caches.

Aggregate example outputs are included only when they contain no patient-level
records or identifier lists.

Users are responsible for complying with the current PhysioNet terms applicable
to the database versions they access.


The local frozen MIMIC analysis configuration identified the source release as MIMIC-IV v3.1.
