# Aggregate example outputs

These files contain aggregate, non-patient-level results used to verify the published analysis. Internal development/version identifiers have been removed from public-facing filenames. Original internal source filenames are retained only in `SOURCE_PROVENANCE.csv` for auditability.

- `example_outputs/mimic/final_effect_estimates.csv` — Final frozen MIMIC-IV 6-hour effect estimates
- `example_outputs/mimic/bootstrap_summary.csv` — MIMIC-IV patient-cluster bootstrap summary
- `example_outputs/mimic/weight_support_diagnostics.csv` — MIMIC-IV final weight and empirical-support diagnostics
- `example_outputs/mimic/grace_period_event_audit.csv` — MIMIC-IV grace-period event audit
- `example_outputs/mimic/sequential_trial_counts.csv` — MIMIC-IV sequential trial counts by baseline hour
- `example_outputs/mimic/two_hour_design_model_selection.csv` — Outcome-blind diagnostics for the unsupported 2-hour candidate strategy
- `example_outputs/mimic/two_hour_design_recommendation.csv` — Outcome-blind decision record for the unsupported 2-hour candidate strategy
- `example_outputs/eicu/external_effect_estimates.csv` — Frozen eICU external point estimates
- `example_outputs/eicu/external_bootstrap_summary.csv` — eICU bootstrap summary
- `example_outputs/eicu/external_weight_support_diagnostics.csv` — eICU weight and empirical-support diagnostics
- `example_outputs/eicu/external_sequential_trial_counts.csv` — eICU sequential trial counts
- `example_outputs/eicu/external_endpoint_mapping_audit.csv` — eICU endpoint-mapping audit
- `example_outputs/eicu/chronology_sensitivity_effects.csv` — Post-hoc eICU source-data chronology sensitivity effect estimates
- `example_outputs/eicu/chronology_sensitivity_support_check.csv` — Empirical-support check after chronology exclusion
- `example_outputs/eicu/chronology_audit_summary.csv` — Summary of source-data chronology inconsistencies
