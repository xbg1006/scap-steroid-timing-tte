# Aggregate example outputs

These files contain aggregate, non-patient-level results for cross-checking the
published analysis. They contain no patient/stay identifiers or patient-level
weights/trial records.

MIMIC-IV examples include the frozen 6-hour effect, bootstrap summary, support
and weight diagnostics, grace-period event audit, sequential trial counts, and
the outcome-blind diagnostic record for the unsupported 2-hour candidate.

eICU examples include the frozen external point estimate, full-refit bootstrap
summary, weight/support diagnostics, sequential trial counts, endpoint-mapping
audit, and chronology/source-data sensitivity summaries.

Local checkpoint paths have been normalized to repository-relative examples.
